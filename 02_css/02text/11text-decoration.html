text-decoration 속성

텍스트에 밑줄을 긋거나 가로지르는 줄 표시

텍스트 링크의 밑줄을 없앨 때도 사용

예전에는 text-decoration을 밑줄, 윗줄, 취소선 정도로만 설명했지만, CSS3 이후에는 텍스트 장식 관련 속성을 묶는 단축 속성으로 확장

현재는 text-decoration-line, text-decoration-style, text-decoration-color, text-decoration-thickness까지 함께 지정할 수 있습니다. 다만 두께까지 포함하는 형태는 CSS Text Decoration Level 4에서 확장된 최신 문법
