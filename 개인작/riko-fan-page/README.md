# 리코 팬 페이지 — HTML / CSS / JavaScript 연습

## 실행

폴더 전체를 압축 해제하고 VS Code에서 열어 주세요.
index.html을 Live Server로 열면 됩니다. 인터넷 없이도 배경과 폰트가 표시됩니다.

## 파일 역할

- index.html: 제목, 채널 링크, 버튼과 소개 화면의 구조
- style.css: 화면 배치, 글꼴, 여백, 반응형 크기
- script.js: 마우스 물결, 물결 켜기/끄기, 소개 화면 열기/닫기
- assets/spring-water.png: 배경 원본
- assets/hurricane.ttf: 첫 화면 제목용 Hurricane 글꼴
- assets/allura.ttf: 소개 화면용 Allura 글꼴
- assets/barlow.ttf: 소제목과 버튼용 Barlow Condensed 글꼴
- assets/star.svg: 연습용 파비콘

## 이번 수정

- 글자 색상은 커서 주변에만 물결처럼 번집니다. 제목은 최대 반경 82px, STELLIVE는 42px입니다.
- 커서를 따라 색상 영역도 이동하고, 나가면 검정색으로 돌아옵니다.
- Discover Riko 클릭: 수면이 아래에서 올라오며 첫 화면이 위로 멀어지고, 소개 화면이 나타납니다.
- 유튜브·X·치지직 아이콘 뒤에 부드러운 흰색 그림자를 적용했습니다.
- 기존 Hurricane 폰트, 전경 입체감, 배경 시차, 검정 물결 버튼, 수면 굴절은 유지합니다.
- 움직임 줄이기 설정에서는 잠수 전환 없이 즉시 소개 화면을 엽니다.

## 수정하기

버튼 문구와 소개 내용은 index.html에서 바꿀 수 있습니다.
중앙 제목 크기는 style.css의 h1, 위치는 .hero-copy에서 바꿉니다.
이미지를 바꿀 때는 assets/spring-water.png 파일을 교체하면 됩니다.
배경은 화면을 채우므로 화면 비율에 따라 가장자리가 잘릴 수 있습니다.

## 물결

배경과 제목·로고·아이콘·버튼을 하나의 화면으로 합성해 같은 파동으로 굴절시킵니다.
실제 HTML은 투명한 상태로 남아 링크·키보드·접근성 기능을 유지합니다.
작은 격자에서 물 높이를 계산해 손가락으로 수면을 만지는 잔물결을 표현합니다.
WebGL이 가능한 환경은 셰이더로 합성 화면을 굴절시킵니다.
WebGL이 불가능한 환경은 Canvas 2D의 간단한 물결로 전환됩니다.
마우스를 움직이거나 배경을 클릭해 보세요. Water on/off로 멈출 수 있습니다.
운영체제의 움직임 줄이기 설정이 켜져 있으면 처음에는 물결을 끕니다.
한 장의 배경 이미지에 깊이별 시차와 수면 굴절을 적용한 2.5D 효과입니다.
실제 3D 모델이나 자유롭게 회전하는 카메라는 아니므로 가려진 면이 드러나지는 않습니다.
